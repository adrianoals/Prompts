# Prompts

Este repositório serve para armazenar prompts usados em desenvolvimento.

## Objetivo

Centralizar prompts para facilitar:
- reutilização em diferentes tarefas
- padronização de fluxos de trabalho
- manutenção e evolução contínua dos prompts

## Estrutura atual

- `prompt/`: arquivos de prompts e templates utilizados no dia a dia

## Observação

Os conteúdos podem ser atualizados conforme novos processos e necessidades do desenvolvimento.
