# Executando Auditoria de Dependencias

Use o agente `dependency-auditor` para executar uma auditoria de dependencias no projeto.

**Pasta do projeto para auditar:** `$PROJECT_FOLDER`

Se o usuario nao fornecer a pasta do projeto para auditar, execute a auditoria em todo o projeto. Caso contrario, audite apenas a pasta fornecida pelo usuario.

---

# Siga a especificacao do agente

Pense profundamente em cada etapa da especificacao do agente (`@dependency-auditor.md`). Em seguida, execute a auditoria completa de dependencias no projeto, seguindo rigorosamente as instrucoes definidas na especificacao do agente dependency-auditor.

**NAO ESQUECA!** Apos gerar o relatorio completo, se o usuario ainda nao tiver fornecido um caminho e nome de arquivo, pergunte explicitamente:
"Voce quer que eu salve este relatorio em um arquivo? Se sim, por favor forneca o caminho e o nome do arquivo."
